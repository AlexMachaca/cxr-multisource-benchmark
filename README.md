# Joint classification of infectious and occupational lung diseases on chest X-rays

*Versión en español: [README_ES.md](README_ES.md).*

Code and aggregated results for the paper *Joint Classification of Infectious and Occupational Lung Diseases on Chest X-Rays: A Benchmark of
Convolutional, Transformer, and Hybrid Networks* (Machaca-Chuquimamani and Ibarra-Cabrera, submitted to *BioMedInformatics*, MDPI).
<!-- TODO al publicar: agregar DOI del artículo y del archivo de Zenodo -->

The study benchmarks ten architectures (4 CNNs, 3 Transformers, 2 hybrids and a custom CNN–Transformer) on a curated dataset that merges seven
public chest X-ray sources into six classes (Normal, Pneumonia, COVID-19, Tuberculosis, Silicosis, silicotuberculosis), with a common
two-stage transfer-learning protocol, four dataset variants, paired statistics, run-to-run variability, per-source evaluation and
occlusion/Grad-CAM analyses.

> **What is NOT in this repository.** Radiographs, trained weights, per-image manifests and per-image predictions are not distributed: two of the
> sources (SilicoData and VinDr-CXR) forbid redistribution of the data or of material derived from it. See `docs/DATA_ACCESS.md` to obtain the data
> from the original providers. Everything else (code, notebooks, aggregated metrics) is here.

## Layout
The folder names are those of the original project (in Spanish) so that every script runs without changing paths.

| Folder | Content |
|---|---|
| `notebooks_eda/` | Exploration and curation of each source (`00`–`06`), cross-source perceptual-hash comparison (`07`) and construction of the final dataset and its manifests (`08`). **Outputs were removed** because they embed radiographs. |
| `notebooks_entrenamiento/` | Training notebooks for the 10 architectures (`entrenamiento_<model>_variantes.ipynb`, the 40 main runs; Google Colab, Tesla T4), `entrenamiento_<model>.ipynb` (first run of the six-class variant with exclusion, "run A"), `entrenamiento_resnet50_radimagenet.ipynb`, `entrenamiento_utils.py`, `preresize_dataset.py`, the analysis notebooks (`analisis_*`, `comparacion_modelos`) and `benchmark_latencia.py`. |
| `notebooks_app/` | `gradcam_clasificadores.py` and `explicabilidad.py`: occlusion tests and Grad-CAM. |
| `figuras/` | Scripts that generate the paper figures (Fig. 1–2 and 3–10) from the result files. |
| `Redaccion/manuscrito/generar_tablas_resultados.py` | Generates Tables 8–13 (LaTeX) from the result files. |
| `resultados/` | Aggregated results only (CSV/JSON): per-model metrics, confusion matrices (counts), bootstrap intervals, McNemar tests, STB decomposition, replicate analysis, per-source tables, occlusion tables, latency. |

## Environment
- Training (Google Colab): Python 3.13, PyTorch 2.11.0, torchvision 0.26.0, timm 1.0.30, CUDA 13.0, Tesla T4.
- Analysis, latency, occlusion and Grad-CAM (local): Python 3.12, PyTorch 2.14, torchvision 0.29, timm 1.0.29–1.0.30.
- CPU analysis environment: `uv sync` (uses `pyproject.toml`) or `pip install -r requirements.txt`; GPU: `pip install -r requirements-gpu.txt`.

## Reproducing the results
1. Obtain the datasets (`docs/DATA_ACCESS.md`) and place them under `Datasets/`.
2. Curation: run `notebooks_eda/00` … `08` in order (seed 42). This creates `dataset_final/` and the manifests.
3. `python notebooks_entrenamiento/preresize_dataset.py` creates `dataset_final_224/` (224×224, bilinear; identical pixels to resizing on the fly).
4. Training: run the notebooks in `notebooks_entrenamiento/` (they expect the folder layout of the original project; paths are set in the first cells).
5. Analysis: `analisis_4_variantes`, `analisis_por_fuente`, `analisis_replica_radimagenet`; then
   `python figuras/figuras_resultados/generar_figuras_resultados.py` and `python Redaccion/manuscrito/generar_tablas_resultados.py`.

To check the numbers of the paper without retraining, the aggregated files in `resultados/` are enough: `generar_tablas_resultados.py` and
`generar_figuras_resultados.py` run from them. The analysis notebooks (`analisis_*`) need the per-image predictions (`*_predicciones.npz`) written by the
training notebooks, which are not distributed; their saved outputs are kept in the notebooks.

Training was performed **without a fixed random seed** (see the paper, Sections 3.9 and 4.7 for the measured run-to-run variability), so retraining will
give results that differ from the paper by about the amount reported there.
